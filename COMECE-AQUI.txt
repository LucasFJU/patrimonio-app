PATRIMÔNIO — SEU APLICATIVO DE INVESTIMENTOS

1. Extraia o ZIP e abra a pasta patrimonio no Codex ou VS Code.
2. Leia README.md: contém os passos para executar e publicar na Vercel.
3. Com Node.js instalado, execute na pasta:
   npm ci
   npm run dev
4. A carteira funciona em modo local sem cadastrar chaves.
5. Para sincronizar os aparelhos: configure Supabase conforme o README.
6. Para a análise mensal: configure BOLSAI_API_KEY e SUPABASE_SERVICE_ROLE_KEY na Vercel, além do agendamento.
